## 3. 字段口径（对应规则总结 §3）

| 字段 | 口径 |
|---|---|
| `icao_code` | **ICAO DOC 8643 型号设计符**（2–4 位，唯一）——就是你说的"缩写"（A359、B77W、B738），无需新增字段 |
| `manufacturer` | `Airbus` / `Boeing` / `COMAC` |
| `model` | 官方完整型号（`A350-900`、`737 MAX 8`、`C909`、`C919`），不细分发动机/航司子型号 |
| `model_zh` | 中文（`空客 A350-900`、`波音 737 MAX 8`、`商飞 C909`） |
| `notes` | 仅记录覆盖关系（如 B763 含 -300ER）、neo 系列说明等 |

## 4. 回答你的两个问题

**① 777-300 与 777-300ER 需要分开吗？—— 需要，已分开。**
- ICAO 型号代码不同：`B773`（777-300）vs `B77W`（777-300ER）；
- 表规则 `icao_code UNIQUE` 决定它们本来就是两行；
- 实际意义：航程、载重差异大，是两种"飞得不一样"的飞机，记录航班时值得区分。

**② 需要加字段显示 A359 这类缩写吗？—— 不需要，`icao_code` 就是它。**
- `icao_code`（2–4 位）存的就是 ICAO 设计符缩写，UI 要显示缩写徽章直接取这个字段；
- `model`（≤160）存完整型号 A350-900；`model_zh` 存中文；
- 再加字段会与 `icao_code` 完全重复，且没有任何校验规则需要它。
